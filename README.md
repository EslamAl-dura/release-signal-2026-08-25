# Release Signal

Release Signal is a bilingual deployment-readiness cockpit built with React, Vite, TypeScript, TanStack Router, TailwindCSS, and shadcn-style UI primitives.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run build
npm run lint
```

The dashboard calculates a weighted readiness score from quality, reliability, observability, and rollback signals. Open Signal details to tune inputs, or switch the interface to Arabic for RTL review workflows.
